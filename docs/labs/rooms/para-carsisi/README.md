# Para Çarşısı (Kişisel veri ve para)

Gençler artık kendi kartlarıyla, ailelerinin kartlarıyla ve oyun cüzdanlarıyla alışveriş yapıyor. Dolandırıcılar da bunu biliyor: "bedava", "çekiliş", "kolay para" ve "hesabını kirala" teklifleri doğrudan bu yaşa yapılıyor.

Bu klasör Para Çarşısı odalarının senaryolarını tutar. Planın kısa hâli (hikâye, tuzak, doğru karar, ana soru) `docs/labs/room-plan.md`'de; buradaki dosyalar odanın **tam metnidir** (mailler, mesajlar, kartlar, sorular, geri bildirimler). Nasıl yazılacağı: [../README.md](../README.md).

- `training/`: eğitim odaları (temel ve ileri eğitimler)
- `scenario/`: senaryo odaları
