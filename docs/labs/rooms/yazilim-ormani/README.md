# Yazılım Ormanı (Zararlı yazılım)

Bu yaşta zararlı yazılım çoğunlukla "bedava" bir şeyle gelir: hile, mod, korsan film, bulunmuş bir bellek, ödev diye gelen bir dosya. Bir kez kurulunca hesaplar, dosyalar ve arkadaş listesi tehlikeye girer.

Bu klasör Yazılım Ormanı odalarının senaryolarını tutar. Planın kısa hâli (hikâye, tuzak, doğru karar, ana soru) `docs/labs/room-plan.md`'de; buradaki dosyalar odanın **tam metnidir** (mailler, mesajlar, kartlar, sorular, geri bildirimler). Nasıl yazılacağı: [../README.md](../README.md).

- `training/`: eğitim odaları (temel ve ileri eğitimler)
- `scenario/`: senaryo odaları
